# Skills

Skill cấp workspace dùng cấu trúc `<skill-name>/SKILL.md` và chỉ được nạp khi task
khớp mô tả. Skill cung cấp chuyên môn lặp lại; không thay thế role, workflow hoặc
Plan và không được tự mở rộng phạm vi người dùng giao.

`audit-agent-environment` là skill read-only để kiểm tra hạ tầng Agent.
