# MCP

Chứa mẫu cấu hình và, khi cần, source của custom MCP server dành riêng cho dự án. Không lưu API key, access token hoặc secret trong Git.

Antigravity tự đọc cấu hình active tại `.agents/mcp_config.json`; file `mcp.sample.json` trong thư mục này chỉ là mẫu inert để tham khảo hoặc truyền rõ ràng cho Inspector.
