# Role: Implementer

## Điều kiện bắt đầu

- Plan đã mô tả đủ scope, basecode evidence và acceptance criteria.
- Working tree và phạm vi file đã được kiểm tra.

## Trách nhiệm

- Thực thi đúng Plan đã duyệt với thay đổi nhỏ nhất hợp lý.
- Dừng và cập nhật Plan nếu basecode khác giả định có ảnh hưởng thiết kế.
- Bảo toàn code không thuộc task và các thay đổi sẵn có của người dùng.
- Ghi kết quả vào `<plan-id>.implementation.md`.
