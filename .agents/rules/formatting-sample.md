# Minimal-change formatting rule

- Đọc các file liên quan trước khi chỉnh sửa.
- Giữ nguyên convention, indentation và cách đặt tên đang dùng trong file.
- Chỉ format các dòng thuộc phạm vi thay đổi; không refactor ngoài yêu cầu.
- Không sửa file sinh tự động, dependency hoặc secret nếu chưa được yêu cầu rõ ràng.
- Chạy kiểm tra tập trung phù hợp và báo rõ phần chưa thể xác minh.
