# Plugins

Chứa bundle mở rộng của Antigravity. Plugin thực tế phải nằm tại `<plugin-name>/plugin.json` và có thể đóng gói rules, skills, MCP servers hoặc hooks.

`plugin.sample.json` là manifest mẫu inert. Chỉ tạo thư mục plugin thật khi có chức năng cụ thể để tránh component rỗng bị auto-discover.
